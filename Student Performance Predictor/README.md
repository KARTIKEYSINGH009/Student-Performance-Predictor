# Student Performance Predictor

This project predicts whether a student will **Pass or Fail** based on their **marks**, **attendance**, and **daily study hours** using a simple **Logistic Regression** model.

---

## Project Overview
The model is trained on a **synthetic dataset** generated using random values for marks, attendance, and study hours.  
It then predicts the student’s performance with a probability score.
